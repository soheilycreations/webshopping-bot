│ 📞 QUICK TROUBLESHOOTING                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

❌ Bot not replying
  ✓ Check: Auto-Reply is ON (Settings page)
  ✓ Check: Knowledge Base has FAQs or documents
  ✓ Check: WhatsApp shows "connected" ✓
  ✓ Wait 15 seconds (Render server is slow at first)

❌ QR code won't scan
  ✓ Use phone camera to scan
  ✓ Make sure good lighting
  ✓ QR expires in 30 seconds - rescan quickly

❌ "Not Found" error on website
  ✓ Wait 5 minutes after deploy
  ✓ Refresh browser (Ctrl+F5)
  ✓ Check URLs are exactly correct

❌ Can't login to dashboard
  ✓ Clear browser cache (Ctrl+Shift+Delete)
  ✓ Try different browser
  ✓ Check internet connection
